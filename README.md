# MacWand downloads

Public downloads for MacWand. This repository contains release files and installation instructions; the application source code is maintained separately.

## Download for macOS

**[Download the latest MacWand release](https://github.com/kararliadam/MacWand-dist/releases/latest)** and choose the `.dmg` file under **Assets**.

- Requires macOS 15.6 or later. The Mac app supports Apple Silicon and Intel Macs.
- Open the DMG and move MacWand to Applications.
- Open MacWand from Applications and grant the macOS permissions needed for the features you use. Remote control of this Mac requires **Accessibility**; screen and audio sharing requires **Screen & System Audio Recording**.
- MacWand starts in the menu bar. To control another Mac, install MacWand on that Mac too and pair the devices.

The Mac download is signed and notarized by Apple. Verify a download against the SHA-256 value in its release notes if desired. Updates are published on the [Releases page](https://github.com/kararliadam/MacWand-dist/releases); the app does not update itself automatically yet.

## iPhone

The iPhone app is distributed to invited testers through Apple TestFlight. An iOS IPA is not offered for direct installation here.

## Türkçe

Mac sürümünü [son sürümler sayfasından](https://github.com/kararliadam/MacWand-dist/releases/latest) indirip **Assets** altındaki `.dmg` dosyasını açın. MacWand’ı Uygulamalar klasörüne taşıyın. En az macOS 15.6 gerekir; Apple Silicon ve Intel desteklenir. Uzaktan kontrol için **Erişilebilirlik**, ekran ve ses paylaşımı için **Ekran ve Sistem Sesi Kaydı** iznini verin. iPhone sürümü davetli test kullanıcılarına TestFlight üzerinden dağıtılır.
